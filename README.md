# War Robots-inspired Godot hangar UI mockup

This project is a static Godot interface mockup inspired by mobile mech game hangar screens.

Features included:
- top status bar with resources and player avatar
- central preview panel
- weapon/equipment section
- 6 empty hangar slots
- bottom navigation bar
- large deploy button

Usage:
1. Open this folder in Godot 4.
2. Import the project.
3. Press Play.

This is intentionally UI-only. No real battle or robot functionality is implemented.
