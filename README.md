# Mech Assault

This project is an original mech combat hangar mockup built to feel like a premium sci-fi robot battler interface while preserving the existing game systems.

Features:
- dark stealth-tech hangar environment
- large central robot staging area with layered depth
- compact top command bar with resources and pilot status
- dedicated stats and equipment side panels
- empty slots treated as physical hangar docks instead of blank cards
- bottom navigation and a dominant battle CTA
- original Mech Assault styling that stays distinct from proprietary game art and branding

This project is UI-focused only and intentionally does not replace the underlying gameplay logic.

Open in Godot 4 and run the hangar scene to preview the mockup.
